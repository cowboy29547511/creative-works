# 劉奐廷 2026 作品集

AI 影像 × 互動設計 × 遊戲開發的個人作品集網站（繁體中文）。

## 內容
- **代表作 01｜《多比歷險》**：AI 同人預告片，從劇情、分鏡、圖片生成、運鏡規劃到剪輯皆獨立完成
- **代表作 02｜《鯨落之城》**：AI 短片
- **代表作 03｜《霧潮星島》**：可直接遊玩的復古動作生存遊戲（採集 › 製作 › 點燈 › 打王 › 通關）
- **代表作 04｜輕賽博美術展廳**：3D／WebGL 互動網頁
- **企業社群宣傳影片**：前公司任內製作的 Shorts 與影片（連結至 YouTube 原片）
- 其他作品：字幕翻譯工具、剪片 Skill、家庭共用相簿、照片自動分類

## 本機預覽
影片需要支援 Range 請求的伺服器才能拖曳進度，例如：
```bash
npx serve .
```
然後開啟 http://localhost:3000

## 結構
```
index.html        主頁（單一檔案，含 CSS / JS）
game/index.html   《霧潮星島》遊戲
works/            互動網頁作品
media/            影片、劇照、縮圖
```
